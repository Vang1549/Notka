# Редактор 0.75 — Своя сцена

Обновляется подписанный пакет редактора с прежнего сервера. APK 0.68 и панель 0.60 не изменены; minApk 64. GitHub в этой публикации не используется.

Базовая сцена: полные использованные октавы от До до Си, первая дорожка зелёная, вторая синяя, дальнейшие цвета вычисляются из сохранённого случайного seed. Чёрный фон, матовые ноты, скругление 25%, лёгкое свечение и искры, подсветка клавиш, 60 FPS и сбалансированная чёткость. Повтор остаётся на HUD.

Настройки справа; слева снизу миниатюра текущей сцены, сверху независимая демонстрация нот. Для дорожек по порядку используются До, Ре-диез, Фа, До следующей октавы, затем следующая четвёрка. Неполная последняя группа играет только оставшиеся дорожки. Демонстрация использует их инструменты и настройки, отдельные голоса и переключатель звука. Закрытие, фон и новое изменение отменяют прежнюю демонстрацию; основной транспорт не меняется. Фон обновляется без повторного аккорда.

Выбор пресета сразу применяет его. Трек хранит имя выбранного пресета; для старых сохранений возможен поиск по совпадению оформления, с учётом переназначенных инструментов. Сохранить как новый и Обновить выбранный всегда присутствуют под выбором; недоступные действия тусклые. Обновление не требует подтверждения. Мусорка у пользовательского пресета открывает подтверждение удаления; отмена ничего не меняет. Удаление активного пресета оставляет текущее оформление трека. Базовый нельзя удалить.

Один регулятор скорости 0.1–10× с ползунком 0.01 и точным вводом 0.001. Схема настроек 2 объединяет прежние скорость и вертикальный масштаб произведением; повторное чтение его не умножает. Старое автоматическое кадрирование сохраняется до выбора базового пресета. Темп музыки не меняется.

Цвета и фон разделены. Выбор цвета: две строки образцов, затем прозрачный / исходный цвет палитры / свой цвет. Прозрачность сохраняет звук, убирая ноты, подсветку клавиш и привязанные эффекты, в том числе при экспорте через общий renderer.

Проверены пресеты, сохранение/импорт/экспорт сцены, аккорды 4+4+1, стабильные цвета, миграция скорости, отдельный звук, отмена асинхронной загрузки, невидимые ноты, пауза/перемотка/повтор, Back и автосохранение. Проверки пакетов включают нативную распаковку, подписи, хеши, откат при повреждении и ленивую загрузку renderer. Браузерный предпросмотр инфраструктуры обрывал HTML до скриптов; его результат не подтверждает интерфейс. Реальное Android/WebView и звучание на телефоне не проверены.
