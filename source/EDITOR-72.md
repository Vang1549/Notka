# Редактор 0.72, APK 0.64, панель 0.56

## Исходники и сборка

Редактировать `app/editor/*.js`, `editor.css` и `shell.html`. Порядок исходных модулей указан в `modules.json`. `app/index.html` — генерируемая совместимая страница для регрессионных тестов; не редактировать вручную. `node build-editor.cjs` обновляет её и `.native-build/editor/`. Разделение исходников сохраняет общий лексический контекст и порядок инициализации существующего редактора.

Пакет содержит HTML, CSS, минифицированный runtime, отдельно загружаемые `scene-renderer.js` и `media-export.js`, лицензию библиотеки. Визуализатор загружается при первом показе сцены/её настроек, медиаэкспорт — при первом открытии сохранения аудио/видео. Модули берутся только из запущенного пакета. У старых редакторов медиаэкспорт продолжает использовать APK-ресурс.

Сохранять читаемые исходники. Не сокращать имена/пояснения вручную ради размера. Минификация и ZIP-сжатие выполняются сборкой. Не оценивать производительность по числу символов: отдельные проверки покрывают кэш геометрии, виртуализацию сетки, аудиопланировщик и выгрузку неиспользуемых звуков.

## Пакеты и переход со старого формата

`dist/editions/` неизменён: старые APK видят редакторы до 0.71. APK 0.64 читает `dist/bundles/catalog.json`, содержащий также исторические версии. Новые записи имеют `format: 2`, `minApk: 64` и SHA-256 ZIP. Подписанный `manifest.json` внутри ZIP фиксирует номер версии, имя, минимальный APK и точный набор файлов с размерами и SHA-256.

Загрузка идёт через DownloadManager прямо в нативный установщик. Полный архив не проходит через JavaScript/localStorage или Intent. Проверяются архивный хеш, RSA-подпись манифеста, файлы и их хеши. Временный каталог переименовывается в окончательный только после полной проверки. Неудачная загрузка не удаляет предыдущие версии. Встроенные 0.71 и 0.72 доступны без интернета; пользователь может выбрать прежнюю версию.

При запуске через Intent передаётся только идентификатор пакета и небольшие параметры. Исторические HTML-редакторы тоже сначала сохраняются в приватный файл. WebView получает HTML из файла и ресурсы через перехватчик фиксированного HTTPS-origin; общий доступ к файлам, контенту и сети остаётся отключённым. Нативный мост не позволяет произвольные пути. Активный пакет защищён файловой блокировкой от удаления.

190000 символов остаётся только в обработчике старого формата для совместимости. Новый формат ограничивает архив 8 МиБ, отдельный распакованный файл 8 МиБ, сумму 24 МиБ, количество файлов 64. Это защита распаковки/памяти, а не бюджет исходного кода. Её можно пересматривать с измерениями; уже текущий тест устанавливает runtime >300000 символов.

Кэш декодированных инструментов удаляет неиспользуемые банки при превышении 64 МиБ. Банки дорожек и текущей предпрослушки сохраняются, поэтому это мягкий бюджет: крупный используемый проект может занимать больше. Формат, частота дискретизации и качество звука не меняются. Уже работающие голоса держат собственные ссылки на AudioBuffer.

## Проверки

Из `source/`: `python verify.py`, `python test-native.py`, `python test-background-service.py`, `python test-bundles.py`; `node test-launcher.cjs`, `node test-bundle-panel.cjs`, `node test-update.cjs`, `node test-catalog.cjs`, `node test-lazy-modules.cjs`, `node test-audio-cache.cjs`, актуальные тесты сетки/звука/дорожек/сохранений/экспорта. Из корня: `python scripts/publish.py --verify-only`, `python scripts/test_apk_delta.py`.

Все автоматические наборы теперь запускаются через `npm test`; полный порядок, зависимости и границы проверки описаны в [TESTING.md](TESTING.md). `test-editor6.cjs` обновлён под текущую геометрию, время жестов и поведение редактора. Проверки интерфейса импорта, библиотеки и сохранений используют искусственный PCM-банк и больше не пропускаются без личной шкатулки. Отдельно и явно пропускается только проверка оригинального Floe-аудио, если пакет автора не предоставлен. Android-устройство/эмулятор в среде сборки отсутствует; установка и поведение системного WebView требуют проверки на телефоне. Локальный Chromium также недоступен из-за ограничений среды, поэтому успешный браузерный запуск не заявляется.

## Публикация

Не менять выпущенные ZIP и APK. Новый код редактора — новый номер пакета. Сначала проверить и опубликовать APK в Releases, проверить скачанный хеш, затем обновить подписанный `channel.json`. Не включать приватный ключ в репозиторий или публикацию.

`release-inputs/*.delta` при наличии — только средство доставки готового подписанного APK в GitHub Actions. Публикатор восстанавливает точные байты из предыдущего публичного APK, проверяет хеши и выкладывает обычный полный APK. Это не патч, устанавливаемый на телефоне, и ключ на runner не передаётся.
