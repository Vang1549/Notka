# APK 0.63 · Открытые обновления

Обновления APK загружаются из публичных GitHub Releases Vang1549/Notka. Подписанные каталоги редакторов и инструментов — из dist в main того же репозитория. Страница выпусков открывает GitHub Releases. Панель 0.55, встроенный редактор 0.71. Подпись APK прежняя; данные приложения не мигрируют и остаются на устройстве.

Управление скачанными файлами распознаёт APK со старого сервера и из нового строго заданного репозитория. Номер в теге выпуска обязан совпадать с именем APK. Проверки цифровых подписей и SHA-256 сохранены.

Проверено: сборка Java/DEX, подписи APK, манифест и ресурсы; тесты обновлений, запуска, сетки, панели дорожек/инструментов, фоновых служб, ограничений управления файлами. Физический Android недоступен. Старый сервер сохраняет APK 0.63 и подписанный channel.json для одноразового перехода уже установленных приложений.
