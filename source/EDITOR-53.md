# Редактор 0.53 · Меню по местам

Удалена кнопка «Визуальный проигрыватель» из настроек редактора и её обработчик/ссылка в блокировке файловых действий. Оформление сцены доступно через шестерёнку самого проигрывателя, включая остановленную сцену. Сохранённые параметры не меняются.

Крестик удаления сохранённого трека центрирован независимо от общего выравнивания кнопок списка по левому краю. Кнопка и её колонка имеют ширину 44 px и минимальную высоту 44 px. Длинные названия по-прежнему сокращаются с многоточием, не сдвигая крестик. Подтверждение удаления сохранено.

Удаление не менялось: нативный deleteSong удаляет файл .notka через ContentResolver.delete из Download/Notka на Android 10+, либо File.delete из каталога приложения на старых Android. Из списка файл пропадает только после успешного нативного удаления. Если удалён открытый файл, редактор сохраняет текущую композицию и автокопию, отвязывая их от имени удалённого файла. Другие копии и экспортированные файлы не удаляются.

Проверены test-tracks.cjs и test-scene.cjs на исходном и упакованном редакторе, существующие случаи удаления/отмены/ошибки/сохранения открытой композиции из test-personal48.cjs отдельно от отсутствующего приватного звукового банка. В браузере с тестовым нативным мостом проверены меню редактора, доступ к настройкам сцены, центрирование крестиков при длинном и коротком названии, открытие и отмена подтверждения. Физический Android не проверялся.

Выпуск только редактора через подписанный каталог; APK остаётся 0.51.
