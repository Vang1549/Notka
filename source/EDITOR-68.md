# 0.68 · Музыка в фоне

APK 0.57, панель 0.52. Экспорт аудио/видео поддержан foreground-службой Android с PARTIAL_WAKE_LOCK, прогрессом, отменой из уведомления и завершающим уведомлением. Сворачивание/блокировка не отменяют медиазадачу. Расчёт остаётся локальным, файлы и форматы прежние.

Служба не заменяет рендерер: она удерживает процесс и CPU, пока существующий WebView рассчитывает OfflineAudioContext/Canvas/WebCodecs. Активность сохраняется на время задачи; onPause/onStop не уничтожают её WebView. Стандартная политика приоритета renderer остаётся IMPORTANT. На Android 9+ служба работает в :editor вместе с Player, на Android 5–8 используется LegacyExportService в основном процессе вместе с PlayerLegacy. Разделение исключает потерю состояния между процессами.

Новый код native/studio/notka/piano компилируется ECJ + D8 в classes2.dex (Android 5+, без дополнительных runtime-библиотек). build-native.py проверяет SHA-256 фиксированных инструментов из native-tools.json. Инструменты находятся в игнорируемом кэше, не включаются в APK или публикацию. Существующий host.ops вызывает шесть публичных статических методов ExportRuntime через короткие JS-мосты. onDestroy редактора завершает службу; экспорт не восстанавливается автоматически после завершения процесса.

Начало: служба запускается по действию пользователя, получает foreground-статус и ограниченный wake lock; JS ждёт подтверждения готовности. Нельзя подменить чужую активную задачу. Ошибка запуска не оставляет фоновый режим и не удаляет файл другой задачи. Частичный wake lock позволяет экрану выключиться; прежний keepScreenOn временно снимается и восстанавливается после экспорта.

JS больше не отменяет медиазадачу по visibilitychange при активной службе. MessageChannel уступает выполнение между кадрами без зависимости от скрытых таймеров. Подготовка банков не требует повторного resume уже существующего AudioContext, чтобы при заблокированном экране не ждать возобновления живого звука. Native-проверка отмены ограничена одним вызовом за 200 мс; прогресс в уведомлении обновляется только при смене целого процента.

Состояние ExportTask синхронизировано между потоком JavascriptInterface и главным потоком Android. Commit атомарно исключает гонку с отменой перед публикацией готового файла. После перехода к финальной записи отмена уже не удаляет результат. При ошибке/отмене уничтожается временный music-export.part; штатная публикация по-прежнему выполняется существующим атомарным finishExport. Wake lock, watchdog и служба освобождаются при завершении, отмене, уничтожении и тайм-ауте. Есть предел 6 часов и watchdog 5 минут без heartbeat, чтобы зависший рендерер не удерживал процессор бессрочно.

Manifest: FOREGROUND_SERVICE, WAKE_LOCK, POST_NOTIFICATIONS, FOREGROUND_SERVICE_DATA_SYNC и FOREGROUND_SERVICE_MEDIA_PROCESSING; сервисы не экспортированы, stopWithTask=true. Тип — dataSync для старых Android (локальный экспорт), mediaProcessing начиная с API 35; onTimeout(int,int) обрабатывается. minSdk21/targetSdk32 сохранены. При запрете уведомлений Android может скрывать их из шторки; foreground-служба всё равно запускается по правилам ОС. Никаких разрешений камеры/микрофона, сетевой обработки или обхода ограничений аккумулятора.

Ограничения: принудительное закрытие, удаление задачи из недавних, остановка процесса системой или перезагрузка прерывают экспорт. Возобновления с контрольной точки нет. Фактическое поведение при блокировке и ограничениях производителя требует проверки на Android; физического устройства/эмулятора здесь нет.

Проверки:
- Настоящая компиляция Java/D8; test-background-service разбирает оба DEX и подтверждает соответствие всех шести bridge-сигнатур публичным статическим методам, а также lifecycle методов службы.
- Java ExportTaskTest: запуск/отмена, монотонный прогресс, watchdog/deadline, ошибка финализации, 100 конкурентных гонок cancel/commit.
- JS test-media-export: существующие WAV/кодеки/30–60 fps, симуляция hidden страницы с активной службой без отмены, отказ/ошибка службы, отмена из уведомления, pagehide, освобождение на ошибках, защита чужой задачи, прежняя отмена на старом APK.
- APK verify: оба DEX, подпись, сервисы/процессы/типы/permissions; native bridges, launcher/update; packed export, player-HUD, Back, сцена, seek и performance.
- Chromium с тестовым native-мостом: 16.100 с WebM VP8+Opus, 1280×720 / 30 fps, 483 кадра, ffprobe принимает файл. Переключение вкладки не прервало расчёт, но среда оставляет document.visibilityState=visible: это не проверка Android lock-screen/настоящей скрытой страницы. Скрытие отдельно проверено модульной симуляцией.

Упакованный редактор 142209 байт, base64 189612, помещается в старый лимит. Предыдущие подписанные редакторы не изменены. Пользовательские треки, инструменты и пресеты не изменяются.

Основные Android API: https://developer.android.com/develop/background-work/services/fgs/launch , https://developer.android.com/develop/background-work/services/fgs/service-types , https://developer.android.com/develop/background-work/background-tasks/awake/wakelock/set .
