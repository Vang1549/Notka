# Редактор 0.77 — Образец и лупа

Уточнение поведения двух окон после 0.76. Нижний образец теперь полностью неподвижный: renderer получает время 0, отдельного animation frame и часов больше нет. Все образцовые ноты находятся над клавиатурой, без нажатых клавиш, звука и анимированных эффектов. Положение/длина образцов нормализованы по визуальному времени падения, поэтому остаются постоянными при смене скорости. Фон, цвета, форма, ширина, скругление, свечение и диапазон сразу отражают текущие настройки. Музыка композиции не используется.

Верхнее окно непрерывно переходит между демонстрациями созвучных аккордов. Изменения визуала применяются к текущему кадру, сохраняя часы/голоса вместо сброса на каждом движении ползунка. Отдельный выключатель звука, повтор, остановка при закрытии/сворачивании и отмена асинхронной загрузки сохранены.

Лупа — равномерный масштаб 2× по X и Y вокруг зоны удара. Диапазон, количество/геометрия клавиш, ноты, музыкальное время не меняются. Увеличивается весь фрагмент со свечением, искрами, кольцами, следом и клавишами. Границы увеличенного фрагмента обрезаются границами canvas. Повторное касание возвращает 1×. Обычная сцена и экспорт не получают масштаб.

Проверены: одинаковый кадр нижнего образца через 50 секунд; отсутствие нажатых клавиш/звука; неизменная геометрия нижнего образца при скорости 1×/10×; одинаковый коэффициент X/Y лупы; сохранение диапазона, музыки и часов; непрерывное переключение аккордов; немедленное применение настроек; отмена при закрытии. Существующие проверки сцен, пресетов, транспорта, сохранений и пакетов также выполнены. На физическом Android не проверено; прежний браузерный предпросмотр обрывал HTML, его работоспособность не подтверждена.

Редактор 0.77, APK 0.68 и панель 0.60. Прежний ключ подписи и основной сервер; GitHub не обновляется.
