# Редактор 0.66 · Музыка в файле / APK 0.55

В проигрыватель добавлена кнопка сохранения аудио/видео. Диалог содержит имя, тип, формат, для видео — 480p/720p/1080p и 30/60 кадров/с, прогресс и отмену. Выход/Back/касание снаружи сначала отменяет активную операцию; без операции закрывает диалог обратно в проигрыватель. Файлы сохраняются существующим атомарным мостом в Загрузки/Notka (на старых Android — в папку приложения files/Download/Notka).

WAV использует существующий оконный offline-рендер: PCM 16 bit, stereo, 32 kHz, общий микс. Дополнительно предлагаются M4A/AAC, WebM/Opus (.weba), OGG/Opus, MP4/H.264+AAC и WebM/VP8+Opus, только если MediaRecorder.isTypeSupported сообщает поддержку. Неподдерживаемые форматы не отображаются. MP3 не добавлен. Ошибки запуска кодировщика, записи или финализации не создают готовый файл.

Сжатое аудио и видео записываются в реальном времени через собственный Web Audio граф и MediaStreamDestination, без микрофона/камеры. Используется снимок трека: выключенные дорожки исключены, активные инструменты и их параметры сохранены, конец включает release. Видео рендерится той же сценой в отдельный canvas выбранного размера, без HUD/верхнего градиента, с текущими настройками сцены и вступительным падением нот. Аудиопланировщик и визуал используют одно время AudioContext. Повтор принудительно ограничен одним проходом, пользовательский флаг loop не меняется. Экспортный canvas использует точное выходное разрешение независимо от DPR дисплея.

MediaRecorder получает блоки по 500 мс; запись в native-файл идёт последовательно, по 32 КБ. Общий лимит 256 МиБ, предел очереди 16 МиБ. Запись не хранит весь файл в JS-памяти. Streaming WebM получает Duration в первом Info (только сегмент неизвестной длины без SeekHead и без существующей Duration), чтобы проигрыватели показывали длительность. Это расчётная длительность со вступлением и хвостом, возможна небольшая разница до последнего кодированного кадра/аудиопакета; seek-индекс не синтезируется. Реальное число кадров зависит от производительности телефона.

Сворачивание прерывает незавершённую операцию с объяснением. Media tracks, sources, AudioContext, таймеры, RAF, canvas и wake lock освобождаются при успехе, ошибке и отмене. Player WebView держит экран включённым, пока редактор на переднем плане; дополнительных разрешений Android нет.

Новый модуль app/media-export.js встроен только в подписанный APK и читается через фиксированный bridge mediaExportScript; произвольные пути не принимаются. Редактор подключает его как разрешённый inline script с явным API, без eval/Function и без изменения CSP. API 0.66 передаёт снимок проекта, функции звука, сцены и файлового потока. На старом APK кнопка сообщает необходимость 0.55. Исторические редакторы и старые виды экспорта сохраняют работу. Динамическая часть редактора — 142204 байта, 189608 base64, ниже прежнего лимита 190000. Новое сокращение имён включается только флагом --media для 66+; упаковка 65 побайтно совпала с опубликованной.

Проверки: test-media-export (WAV/mute, контейнеры, дорожки A/V, один проход, очистка, некорректные имена, ошибки кодека/диска/финализации, отмена при декодировании, сворачивание, отсутствие кодеков, WebM Duration); native verifier/DEX/MIME/asset/keep-screen-on; подписи APK и каналов; launcher/update; packed editor performance/layout/overlap/selection/copy/background/lane/scene/loop/player-hud/back/rack/track-scene/export; независимый разбор MIDI/ZIP/WAV.

Реальная браузерная проверка упакованного редактора с тестовым native-мостом: WAV 32000 Hz stereo PCM, 250712 bytes/1.958344 s; WebM видео VP8 1280×720 с Opus stereo, 118710 bytes/4.938333 s; WebM audio Opus 48000 Hz stereo, 47000 bytes/2.058333 s. Проверены ffprobe, звуковые данные, кадр видео без HUD и отмена через UI. Тестовый Chromium не поддерживал MP4/M4A/OGG, поэтому эти реальные кодировщики здесь не проверены. Физический Android недоступен; native-сохранение и аппаратные кодеки требуют проверки на телефоне.

APK 0.55 включает редактор 0.66, модуль экспорта и предыдущие публичные редакторы/банки. Панель остаётся 0.52. Личные сэмплы, ключ подписи и тестовые записи в публикацию не включены.
