# Редактор 0.64 · Назад по шагам / APK 0.54

Системная кнопка Back в Player и унаследованном PlayerLegacy передаётся глобальной функции notkaBack через evaluateJavascript на UI-потоке. Старые редакторы без этого входа сохраняют прежнее поведение. Native select и экранная клавиатура обрабатывают Back до Activity. APK 0.54 необходим для аппаратной кнопки; стрелка редактора и Escape используют тот же обработчик в самом редакторе.

Возврат закрывает один уровень: подтверждение удаления/замены → родительское окно; Advanced инструмента → базовые настройки → инструментарий; настройки сцены → проигрыватель → редактор. Сохранение/загрузка/экспорт из меню возвращаются в основное меню редактора. Настройки сцены сохраняются в треке при закрытии, отложенные изменения сбрасываются в автокопию. Незавершённый импорт/экспорт получает запрос отмены, без преждевременного выхода.

В редакторе Back открывает отдельный диалог выхода. Новый трек получает имя; для открытого файла предложены явная замена или новая копия. Стрелка слева, Back и касание вне диалога отменяют выход в любой стадии. Выход выполняется после успешной записи либо после «Выйти без сохранения». Во втором случае принудительно записывается автокопия для «Загрузить последний трек»; при ошибке записи выход блокируется. Ошибка сохранения или занятое имя сохраняют диалог и текущую музыку. Успешный именованный файл позволяет выйти даже при отдельной ошибке автокопии.

Касание затемнённой области вызывает тот же возврат только если началось и закончилось на ней. Движение из ползунка/поля наружу не закрывает окно. Вложенный native select поглощает своё первое касание/Back; подтверждения приложения закрываются по одному. Развёрнутые секции параметров details не считаются отдельными модальными окнами.

Упаковка 64 добавляет --navigation: сокращаются имена функций, кроме native/HTML-входов notkaBack и sourceResume; прежние правила упаковки 1–63 сохранены. Для VM-тестов можно вывести отдельную карту NOTKA_EDITOR_MAP и подключить её вместе с NOTKA_EDITOR_HTML. Эта карта и тестовые алиасы не попадают в редактор. Размер 142460 байт, 189948 base64 — в пределах прежнего лимита 190000.

Проверки: test-back на исходном и упакованном коде; на упакованном — player-hud, scene, loop, scene-presets, track-scene, last-track, lane-menu, rack, selection, copy-notes, export. Браузер: ввод имени с успешным выходом, повторное открытие и выбор замены/копии, отмена, касание вне дорожек, настройки сцены → проигрыватель → редактор → диалог. Подпись APK, манифест, сборка DEX и системный мост проверены автоматически. Физический телефон недоступен, поэтому аппаратный Back и системный select/IME на Android требуют проверки пользователем.

APK 0.54 содержит редактор 0.64 и прежние публичные редакторы/инструменты. Панель остаётся 0.52. Частные сэмплы не добавлялись.
