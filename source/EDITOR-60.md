# Редактор 0.60 / APK и панель 0.52 · Тихое меню

Удалены кнопка последнего трека с главного экрана, подпись версии в настройках панели, сообщение об актуальности редактора, сообщение последнего запуска и большой раздел «Обновление APK». Вместо этого внизу три строки: редактор, APK, панель — текущая и последняя известная версия в скобках. Для редактора на главном экране текущей считается самая новая загруженная версия. Кнопка обновления располагается над соответствующей строкой и появляется только после проверки более нового выпуска. Ошибки и ход загрузки остаются видимыми; обычные успешные проверки не добавляют пояснений.

Панель встроена в APK, поэтому её обновление использует тот же подписанный APK и общий процесс скачивания/проверки/установки. Обе кнопки синхронно блокируются при загрузке и становятся кнопками установки после проверки хеша. Подписанный channel.json теперь содержит необязательное поле panel с code/version. Старые панели игнорируют новое поле. Проверенный ответ сохраняется для отображения последних известных номеров офлайн; до свежей проверки он не включает кнопки обновления. Если номер неизвестен, отображается тире, без выдуманного совпадения. Проверка APK выполняется один раз при загрузке панели. Автоматическая проверка каталога редакторов при возврате сохранена.

Кнопка «Загрузить последний трек» перенесена из вложенного списка загрузок непосредственно в меню редактора рядом с сохранением, загрузкой и экспортом. Сохранены чтение автокопии, подтверждение замены открытого проекта и сообщение об отсутствии автокопии. Автоматической загрузки не добавлено.

APK 0.52 подписан прежним ключом, содержит редакторы по 0.60 включительно и прежние публичные банки пианино/Grand Piano. Нативный DEX совпадает с APK 0.51: меняются встроенные HTML и номер пакета. Нет новых разрешений или изменений в хранении музыки/тем/инструментов.

Проверки: launcher (онлайн/офлайн, выбор старых выпусков, подписи, доступность обновлений, строки номеров, темы); update (подпись канала, текущая/новая/неизменённая панель, общий скачанный APK, хеш, повторная установка); last-track, track-scene и copy-notes на упакованном 0.60; native и verify (DEX, манифест, RSA и APK digest). В браузере шириной 390 px проверены обычное меню, доступные обновления, настройки без подписи и новое расположение последнего трека. Физический Android недоступен для проверки установки.
