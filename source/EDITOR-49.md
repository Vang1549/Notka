# Редактор 0.49 · Ссылка на звук

Обновление только HTML-редактора; публичный APK остаётся 0.47, личный APK — 0.48. Обе оболочки загружают редактор 0.49 из подписанного каталога.

Если в дорожке с нотами указан lib-floe-musicbox-1 и банка нет, появляется ссылка на https://www.frozenplain.com/product/music-box-suite-free. Ссылка также доступна в библиотеке. Никаких аудиоданных FrozenPlain в публичный выпуск не добавлено; импорт Floe пока не реализован. URL берётся из фиксированного списка приложения, не из входного файла.

.notka хранит дополнительный информационный instrumentSources; MIDI содержит текстовую метку с источником, WAV ZIP — ссылку в Readme.txt. Отсутствующий инструмент не подменяется и не мешает сохранению или MIDI. На обычном APK Grand Piano продолжает использовать проверенный скачанный банк. Встроенные банки личного APK сохраняют приоритет.

Совместимость наличия встроенных банков проверяется лениво и кешируется; прочитанные данные переиспользуются при декодировании и освобождаются максимум через 30 секунд, если не использованы. Android WebView не устанавливает WebViewClient, внешние ссылки по умолчанию открываются обработчиком URL. Физический Android в этой сессии недоступен.

Проверки: test-source-links.cjs (исходник и минифицированный редактор), test-personal48.cjs, test-instruments.cjs, test-tracks.cjs, test-export.cjs, test-catalog.cjs. В браузере проверены предупреждение и библиотека.

Сборочные скрипты APK остаются привязаны к личному 0.48; для нового APK нужно отдельное повышение версии. Никогда не публиковать private-48 или APK с PERSONAL-USE.txt.
