# 0.67 · Кадр за кадром

APK 0.56, панель 0.52. Экспорт проигрывателя теперь рассчитывает готовый файл вместо записи в реальном времени. Пользователь выбирает аудио/видео, доступный формат, разрешение и частоту кадров; видит процент расчёта и может отменить. Результат сохраняется существующим атомарным механизмом в коллекцию Notka. При сворачивании незавершённый расчёт отменяется; фонового сервиса нет.

WAV сохраняет оконный OfflineAudioContext-рендер PCM stereo 32 kHz / 16 bit. Тот же PCM поступает в AudioSampleSource небольшими блоками. Видео использует существующий renderScene с детерминированным временем frame / fps, без HUD и без пропусков кадров. Звук и кадры чередуются с ожиданием обратного давления кодировщика. До первого звука добавляется тишина длительностью падения нот; release остаётся в конце. Цикл проигрывателя не влияет на экспорт одного прохода. Интерфейс получает управление между блоками.

Mediabunny 1.65.2 (MIT) упакован esbuild 0.28.2 в фиксированный APK-ресурс. Никаких CDN, удалённых кодировщиков, записи экрана, микрофона или камеры. Форматы: WAV, M4A/AAC, WebM/Opus (.weba), OGG/Opus, MP4/AVC+AAC, WebM/VP8+Opus. Асинхронная проверка canEncodeAudio/canEncodeVideo учитывает размер и fps. Неподдерживаемые варианты скрыты. MP4/M4A зависят от наличия AAC/AVC WebCodecs на конкретном Android WebView; без WebCodecs остаётся WAV. Быстрота зависит от устройства, длительности, сцены и качества; быстрее реального времени не гарантируется.

Контейнеры создаются StreamTarget с 64 КиБ буферизацией и native-записью по 32 КиБ. Новый writeExport(offset,base64) принимает только ограниченные смещения и блоки в существующий фиксированный временный файл exportFile, без произвольных путей. Позволяет дописывать длительность и индексы контейнеров. Общий предел около 256 МиБ. При ошибках/отмене кодировщики закрываются, canvas удаляется, wake lock освобождается, временный файл удаляется. Завершённый файл появляется только после успешной финализации.

Чтобы WebCodecs были доступны, Player загружает декодированный подписанный HTML через loadDataWithBaseURL с локальным HTTPS-origin https://appassets.androidplatform.net/notka/. Сетевые загрузки, доступ к file/content остаются запрещены; CSP не ослаблен. Это origin для локальной страницы, запрос на сервер не выполняется. Сборщик DEX получил invoke-*/range для шести последовательных регистров вызова loadDataWithBaseURL. APK сохраняет minSdk 21; доступность сжатого экспорта определяется WebView/кодировщиками.

Редактор 0.67 проверяет наличие writeExport и сообщает необходимость APK 0.56 на старой оболочке. Упакованный редактор: 142198 байт, base64 189600, ниже старого лимита 190000. Опубликованные редакторы 1–66 не изменены. APK содержит 0.67, прошлые публичные версии и прежние публичные банки; личных сэмплов нет.

Проверки:
- test-media-export: точные 30/60 fps timestamps, последний неполный кадр, начало/окончание PCM, вступительная тишина, отключённые дорожки, обратное давление, позиционная перезапись заголовка, очистка, неверное имя, ошибки кодировщика/записи/финализации, отмена во время подготовки и кодирования, скрытая страница, фильтрация форматов.
- Native verifier и DEX сборка: конструкторы/обработка исключений, ограниченный random-access bridge, локальный HTTPS origin, invoke-virtual/range, прежние мосты, Back, ориентация и MIME.
- Подпись/структура APK, подписи каналов, launcher/update/catalog, идентичность включённого модуля/лицензии, неизменность старых редакторов.
- Упакованный редактор: экспорт, сцена, HUD, Back, performance, seek, loop, selection, track-scene и instruments. Независимый разбор MIDI/ZIP/WAV.
- Реальный Chromium + упакованный редактор + тестовый native-мост: WAV 1.958344 с / 32000 Hz stereo; OGG/Opus; WebM/VP8+Opus 1280×720, 146 кадров при 30 fps и 291 при 60 fps, длительность контейнера 4.840 с. Все кадры от рассчитанной временной шкалы на месте. ffprobe/ffmpeg декодируют без ошибок. Звук OGG совпадает с WAV после компенсации задержки кодека около 1 мс (корреляция 0.99973); звук видео имеет ожидаемое вступление 2.88 с + ту же задержку. Проверены изображение без HUD и отмена через UI.

Физического Android нет. Нативное сохранение и MP4/M4A аппаратными кодировщиками на телефоне здесь не проверены; Linux Chromium не предоставил AAC и эти варианты корректно отсутствовали.

Сборка: установка lockfile-зависимостей, python build.py автоматически запускает node build-media.cjs. Приватный ключ подписи хранится вне репозитория; для сборки предоставляется временно и удаляется из checkout после подписания.
