# Нотка

Музыкальный редактор для Android: дорожки и инструменты, piano roll, визуальный проигрыватель, сохранение проектов, экспорт музыки в аудио и видео.

**[Скачать последнюю версию APK](https://github.com/Vang1549/Notka/releases/latest)** · [Все выпуски](https://github.com/Vang1549/Notka/releases)

Текущий комплект: **APK 0.63 «Открытые обновления»**, панель **0.55**, редактор **0.71 «Наглядная сетка»**.

## Установка и обновление

Скачайте `Notka-63.apk` из последнего выпуска и установите его на Android. Если Нотка уже установлена, установите APK поверх неё: пакет и сертификат подписи сохранены. Удалять приложение перед обновлением не нужно.

APK 0.63 получает подписанные каталоги редакторов и инструментов из этого публичного репозитория, а APK — из GitHub Releases. Для скачивания аккаунт GitHub не нужен. Проверка обновлений остаётся автоматической. Старые APK используют прежний сервер, на котором опубликован переходный APK 0.63.

Android 5.0 и новее с актуальным для устройства WebView. Базовое пианино и Grand Piano встроены. Музыкальная шкатулка Music Box Suite Free импортируется пользователем из оригинального пакета Floe; сам пакет в репозитории не распространяется.

## Структура

- `source/app/` — редактор, панель, звуковой движок и экспорт.
- `source/native/`, `source/host.ops`, `source/updater_dex.py` — Android-службы и WebView-мост.
- `source/build.py` — сборка APK; `source/native-tools.json` закрепляет версии и SHA-256 инструментов.
- `source/test-*`, `source/native-tests/` — проверки поведения и форматов.
- `dist/editions/`, `dist/soundbank/`, `dist/channel.json` — подписанные обновления.
- `scripts/publish.py`, `publication.json` — публикация проверенных APK и архивов в Releases.

## Сборка

Нужны Python 3.10+, Java 21, Node.js и npm; Python-пакеты `cryptography` и `Pillow`.

```sh
cd source
npm ci
python -m pip install cryptography Pillow
# Владелец размещает исходный приватный signing.pem локально в source/.
python build.py
python verify.py
NOTKA_DIST=../dist node test-launcher.cjs
node test-grid-preview.cjs
```

Приватного ключа подписи здесь нет. `source/signing.der` — открытый сертификат для проверки выпусков. Для обновления существующих установок нужен исходный приватный ключ; он не должен попадать в Git, логи или архивы.

## Выпуск обновлений

Редакторы публикуются скриптом `source/editor_channel.py`, инструменты — `source/publish_instruments.py`. Уже выпущенные файлы редакторов и инструментов неизменяемы: новые изменения получают новый номер/идентификатор. Проверенные подписанные файлы из `dist` отправляются в этот репозиторий.

Для нового APK сначала соберите и проверьте подписанный файл, затем загрузите его в выпуск `apk-<код>` с именем `Notka-<код>.apk`. После загрузки и проверки SHA-256 опубликуйте соответствующий подписанный `dist/channel.json`. Тег и имя должны содержать один и тот же числовой код.

`publication.json` описывает артефакты с фиксированными SHA-256. Workflow публикации запускается при изменении этого файла или вручную; он проверяет подписи каталогов и хеши, создаёт Releases и не заменяет уже опубликованный APK отличающимся файлом. Для следующих публикаций можно указать `path` к локальному файлу в репозитории вместо исходного `url`. Публикация CLI: `python scripts/publish.py` после входа `gh auth login`.
