## Установка и обновления

Поверх APK 0.69 устанавливается обычное обновление с тем же ключом. Для перехода с прежних версий, подписанных старым ключом: сначала экспортировать нужные треки, затем удалить старую установку и установить 0.70. Закрытый ключ хранится отдельно от репозитория и сохраняется для дальнейших выпусков.

Для перехода на новый канал APK 0.70 нужно один раз скачать из GitHub Releases. Ранее установленный APK 0.69 продолжает обращаться к прежнему сайту; удалённо его адрес не меняется. В 0.70 каталоги, пакеты редактора и звуки загружаются с GitHub, APK — из Releases. Ветка `updates` активируется публикатором только после размещения файлов выпуска; обычные изменения `main` не переключают канал. Старый Site больше не нужен для загрузок новой оболочки.

Android 5.0 и новее с актуальным для устройства WebView. Базовое пианино и Grand Piano встроены. Music Box Suite Free импортируется пользователем из оригинального пакета FrozenPlain; сам пакет в репозитории не распространяется. На физическом телефоне 0.70 ещё не проверена.

Исходники редактора — `source/app/editor/`; `source/app/index.html` генерируется. Оболочка — `source/host.ops` и `source/native/`; сборка — `source/build.py`. Подписанные материалы — `dist/`; описание GitHub Release — `publication.json`.

Из корня проекта в PowerShell:

```powershell
.\scripts\build-local.ps1
```

Сборка использует отдельную среду `D:\Tools\Notka` и рабочую копию в WSL. Версии задаются в `source/release.json`; `release_config.py` синхронизирует значения в панели, редакторе и Java. Для новой версии увеличить нужные номера и выбрать minApk по требуемым возможностям оболочки. Опубликованные APK, ZIP и банки не заменяются другим содержимым.

Ключ: `D:\Tools\Notka\keys\signing.pem`, передаётся через `NOTKA_SIGNING_KEY`. Публичные сертификаты находятся в `source/signing.der` и `source/signing-legacy.der`; закрытый ключ нельзя включать в Git или артефакты.

## Выпуск

Сначала собрать и проверить конкретные файлы, затем подготовить `publication.json`. Workflow загружает готовые APK/ZIP, проверяет хеши и неизменяемость, публикует Release, после чего активирует ветку `updates`. Он не собирает приложение и не требует закрытого ключа. `python scripts/publish.py --verify-only` проверяет также размеры и хеши всех перечисленных файлов, ничего не публикуя.

## Исторические заметки о выпусках

Указанные ниже номера APK относятся к соответствующим прежним выпускам.

Проигрыватель 0.74: полоса времени, пауза, перемотка ±1/10 секунд и скрываемый касанием HUD — `source/EDITOR-74.md`. Пакет устанавливается кнопкой обновления редактора; APK остаётся 0.67.

APK 0.68 / панель 0.60: отчёт диагностики сохраняется как TXT с JSON внутри. На Android 10+ — напрямую в Download/Notka, с IS_PENDING до закрытия и проверки содержимого. На старых Android — через выбор файла с совместимым режимом записи. Ошибки/пустые/неполные файлы не отмечаются как успешные; исходный отчёт остаётся в приложении. Подробности: `source/DIAGNOSTICS-68.md`.

Редактор 0.75: базовая сцена, немедленное применение пресетов, удаление через мусорку с подтверждением, независимые демонстрационные аккорды и прозрачные цвета — [EDITOR-75.md](source/EDITOR-75.md). APK 0.68 и панель 0.60 остаются прежними.

Редактор 0.76: одинаковые окна предпросмотра, приближение аккордов касанием, сменяющиеся созвучия, независимый движущийся образец и ручной ввод чисел возле ползунков — [EDITOR-76.md](source/EDITOR-76.md).

Редактор 0.77: нижний образец неподвижный, верхняя демонстрация непрерывная, лупа равномерно увеличивает весь фрагмент сцены — [EDITOR-77.md](source/EDITOR-77.md).

Редактор 0.78: хроматические гармонии, мелодический статичный образец, единый диапазон клавиатуры и приближение по аккорду с двумя клавишами по краям — [EDITOR-78.md](source/EDITOR-78.md).

Редактор 0.79: пауза/продолжение демонстрации, случайный статичный кадр своего трека, перемотка удержанием и пропорции основного проигрывателя — [EDITOR-79.md](source/EDITOR-79.md).

Редактор 0.80: корзина вместо текста удаления и размер инструмента в скобках рядом — [EDITOR-80.md](source/EDITOR-80.md).

Редактор 0.81: 30 адаптированных тембров GeneralUser GS, категории, отдельное предпрослушивание до скачивания, ухо вместо корзины, удаление удержанием названия — [EDITOR-81.md](source/EDITOR-81.md).
