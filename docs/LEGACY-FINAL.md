# Последний выпуск прежней Нотки

По решению владельца 13 ноября 2026 **APK 0.70, редактор 0.83 и панель 0.61 — последний выпуск прежней реализации**.

Выпуск: https://github.com/Vang1549/Notka/releases/tag/apk-70. Исходный коммит: `dcc9d441abee7048888fbdcc3dd9983c72f2086a`.

Файлы выпуска, подписи и старые пользовательские проекты сохраняются. Канал `updates` продолжает отдавать последнюю прежнюю версию. Он не используется для установки нового приложения поверх старого.

Дальнейшая разработка — самостоятельная Android-Нотка в `next/`, package `studio.notka.next`. Старое приложение остаётся доступным для работы и экспорта .notka. Новая версия разрабатывается с отдельным состоянием и сборкой; старые пользовательские данные не удаляются и не перемещаются автоматически.
