# Разработка Нотки на этом ПК

Основной проект находится в этой папке. Инструменты и временная сборка — в `D:\Tools\Notka`, по решению владельца. Используется уже установленная Ubuntu в WSL; системные Java, Python и Node.js не заменяются.

Явная повторная подготовка инструментов: `py -3.12 scripts/setup-local-tools.py`. Архивы Java и Node проверяются по закреплённым SHA-256 в `scripts/toolchain-downloads.json`, библиотеки Python — по `scripts/python-wheels.json`. Для установки на другом ПК должны уже присутствовать Windows Python 3.12, Windows Node.js и WSL/Ubuntu с Python 3.14; скрипт не устанавливает эти системные компоненты и не создаёт новый ключ. Проверенные версии библиотек записаны в `scripts/python-toolchain.txt`.

## Сборка и проверки

13 ноября 2026 выполнен успешный полный запуск этой команды: APK 0.69 / редактор 0.82 собраны, все выбранные проверки прошли. Подписи APK и встроенного редактора проверены новым открытым сертификатом; проверены принятие прежних подписей, отказ при подмене данных, загрузчик обновлений, атомарная установка пакетов и библиотека звуков. Журнал — `outputs/local-0.69/checks.log`; SHA-256 APK и сертификата — в `build-report.json` рядом. Весь расширенный `npm test` и проверка на телефоне не выполнялись.

Из корня проекта в PowerShell:

```powershell
.\scripts\build-local.ps1
```

Команда копирует актуальные исходники в `D:\Tools\Notka\build`, устанавливает зависимости Node из lock-файла в отдельную папку инструментов при необходимости, собирает APK и редактор, проверяет подписи и выполняет выбранные автоматические проверки. Рабочая папка сборки пересоздаётся: не редактировать исходники там. Оригинальные выпущенные файлы в `dist/` команда не меняет.

Результат появляется в `outputs/local-0.69/`: APK, ZIP редактора, открытый сертификат и отчёт. Полный подготовленный комплект обновлений находится в `D:\Tools\Notka\build\dist`. Это локальная подготовка, а не публикация. Повторная сборка пересоздаёт только этот временный комплект.

Версии APK и редактора задаются в `source/release.json`. Для изменения редактора править `source/app/editor/`; его отображаемая версия находится в `source/app/editor/export.js`. Сборка создаёт `source/app/index.html` автоматически. Для будущего выпуска увеличить соответствующие номера; не заменять уже опубликованные файлы.

## Новый ключ

- Закрытый ключ: `D:\Tools\Notka\keys\signing.pem`.
- Его открытый сертификат: `source/signing.der`; дополнительная копия находится рядом с ключом.
- Старый открытый сертификат: `source/signing-legacy.der`.

Закрытый ключ создан заново с разрешения владельца 13 ноября 2026. Старый закрытый ключ не восстановлен. Новый APK требует переустановки старого приложения; перед удалением сохранить нужные треки экспортом. Пакет приложения остался `studio.notka.piano`.

Новый ключ используется для будущих подписей. Приложение также проверяет сохранённые старые пакеты по закреплённому старому открытому сертификату. Это позволяет оставить старые банки и редакторы неизменными. Произвольные ключи и изменённые данные не принимаются.

Ключ не копируется в Git, комплект обновлений или папку результатов. При переносе на другой компьютер его необходимо передать отдельно и сохранить резервную копию на другом носителе. Без него не получится обновлять установки новой ветки. Переменная `NOTKA_SIGNING_KEY` позволяет явно указать другое расположение; сборка проверяет соответствие сертификату и никогда не создаёт замену автоматически.

## Публикация

Владелец разрешил загрузку версии 0.69 и сделал GitHub основным репозиторием дальнейшей разработки. Ветка `main` содержит исходники и подготовленный комплект `dist/`; выпуск описан в `publication.json`. Старый сайт этой операцией не публикуется.

Адрес обновлений пока сохранён прежний; исходники GitHub и сервер обновлений — разные вещи. Перенос раздачи обновлений на GitHub потребует отдельного решения об адресах и способе размещения.

Полный набор проверок описан в `source/TESTING.md`; локальная команда выполняет проверки, относящиеся к новой подписи, APK, загрузке редакторов и инструментов. Проверка на настоящем Android-устройстве остаётся отдельным шагом.
