# Проверка Нотки 2 1.0.0

Дата: 14 ноября 2026. Это отчёт о конкретной сборке, а не обещание отсутствия ошибок на всех устройствах. APK и SHA-256 зафиксированы в `next/publication.json` и подписанном `next/dist/channel.json`.

## Среда

- Release: `studio.notka.next`, versionCode 1, versionName 1.0.0; подпись отдельная от 0.70.
- Android 15 / API 35, AOSP x86_64, отдельный эмулятор Notka35, 1080×1920, 420 dpi, программная графика, WHPX. Физический телефон не подключался.
- Kotlin 2.1.20, AGP 8.7.3, Gradle 8.9, JDK 21, NDK 27.2.12479018, Oboe 1.9.3. APK содержит arm64-v8a, armeabi-v7a и x86_64.
- Host DSP: MSVC C++17. Проверка звука: Python, NumPy/SciPy; независимое декодирование: FFmpeg.

## Исправлено по результатам проверок

- Примеры инструментов оказались подписанным JSON с MP3: загрузка и проверка теперь используют настоящий формат.
- Убрано распознавание быстрого второго касания как quick-scale, мешавшее переносу нот.
- Начальное положение сетки рассчитывается после получения её размеров.
- Исправлены API-ограничения Android lint, перенос флагов MediaExtractor → MediaCodec и гонка завершения экспортной службы.
- Восстановлена семантика нулевых фаз огибающей и музыкальной длины цикла с хвостами нот.
- Визуальная проверка выявила недостаточный контраст системной строки в тёмной теме; цвет значков теперь выбирается по фону.

## Непроверенное

Физические ARM-телефоны, Android 5–14, задержка динамика/наушников/Bluetooth, нагрев и длительная нагрузка. Не пройдены вручную все сочетания тем, эффектов, жестов и размеров экрана. Оригинальный FrozenPlain Floe-пакет отсутствует: полный импорт не подтверждён. Обновление с 1.0.0 на будущую версию пока не выполнялось. Полная таблица — [PARITY.md](../../PARITY.md).

Старые исходники `source/`, файлы `dist/`, ключ и канал `updates` новым выпуском не изменены. Закрытый ключ Нотки 2, личные песни и лицензируемый личный Floe-пакет в Git и APK не включены.
