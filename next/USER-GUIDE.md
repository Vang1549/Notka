# Нотка 2 — первый запуск

1. Установите **Notka2-1.apk**. В списке приложений появится **Нотка 2**. Старую Нотку удалять не нужно: приложения установлены отдельно.
2. Для переноса песни откройте старое приложение, экспортируйте проект `.notka`, затем в меню новой Нотки выберите импорт. Внутренние сохранения старого приложения автоматически не переносятся.
3. Для быстрой проверки откройте **Memory** из меню и нажмите воспроизведение. Кнопка **Сцена** открывает визуальный проигрыватель.
4. Ноты добавляются касанием сетки. Перетаскивание меняет положение; правый край меняет длину. Пустое место можно протянуть для прокрутки, двумя пальцами — менять масштаб. Режим выделения позволяет работать с несколькими нотами.
5. Инструменты выбираются в библиотеке. Пианино и Grand Piano встроены; дополнительные банки скачиваются с GitHub. Пример можно послушать до загрузки банка.
6. Сохраните важный проект под именем и экспортируйте `.notka` для резервной копии. Автокопия хранит текущую работу, но не заменяет архив всех песен.
7. В экспорте выберите формат и место сохранения. При обычном сворачивании работа продолжается с уведомлением; не завершайте приложение принудительно до окончания.

Music Box Suite Free от FrozenPlain требует отдельного исходного пакета автора. Личные банки не переносятся между приложениями автоматически.

Обновления Нотки 2 устанавливаются новым APK через её собственный канал GitHub. Обновления редактора в старом приложении относятся только к старой Нотке.

Первый выпуск проверен в эмуляторе. На телефоне особенно полезно проверить звук через динамик/наушники, жесты сетки, импорт своей песни и экспорт видео. Если что-то работает неверно, сохраните исходный `.notka` отдельно и сообщите модель телефона, версию Android и последовательность действий.
