# Нотка 2

Новое самостоятельное приложение только для Android. Переписано на Kotlin и C++/Oboe, без WebView и собственного генератора DEX. Идентификатор `studio.notka.next` позволяет устанавливать его рядом с прежней Ноткой.

Первый выпуск — **1.0.0**. [Скачать APK](https://github.com/Vang1549/Notka/releases/download/native-1/Notka2-1.apk) · [Изменения](release-notes.md) · [Проверки и ограничения](reports/1.0.0/RESULTS.md).

Прежняя Нотка: APK 0.70 / редактор 0.83 — последний выпуск прежней реализации. Её исходники, ключи, скачиваемые файлы и канал обновлений сохраняются. Новое приложение не получает доступ к её приватным данным; перенос песен выполняется через экспорт/импорт .notka.

## Архитектура

- `core`: модель проекта, команды редактирования, история, валидация и миграции .notka. Не зависит от Android.
- `app`: нативный интерфейс, файлы Android, библиотека звуков, экспорт и жизненный цикл.
- `audio`: C++-сэмплер и планировщик, общий для живого воспроизведения и экспорта; Oboe обеспечивает вывод звука. В звуковом callback запрещены выделение памяти, чтение файлов и блокирующие операции.
- Ноты и музыкальное время — целочисленные тики с PPQ 960; UI и сцена следуют часам звукового движка.
- Запись проектов атомарная; импорт сначала проверяется целиком. Частичный или повреждённый импорт не меняет открытый проект.
- Все установленные инструменты, SDK, кеши и промежуточные сборки — в `D:\Tools\Notka\next`. Исходники хранятся в этой папке репозитория.
