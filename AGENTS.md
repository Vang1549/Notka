# Нотка — работа с проектом

Основной репозиторий: https://github.com/Vang1549/Notka (публичный).
Работать через подключённый аккаунт Vang1549. Новые исходники и обновления публиковать здесь.

## Устройство проекта
- `source/` — исходники Android, редактора, панели и проверки.
- `dist/` — подписанные каталоги редакторов, инструментов и APK.
- APK доступны в GitHub Releases: `apk-<код>/Notka-<код>.apk`.
- `archive` содержит предыдущие публичные APK и инструменты.
- Старый Sites-хост оставлен для перехода существующих установок на APK 0.63; это больше не основной источник обновлений.

## Выпуски
Сохранять Android package и исходный сертификат подписи. Приватный signing.pem, пользовательские треки и лицензируемые личные пакеты инструментов не публиковать. Открытый signing.der — часть исходников.
Перед новым выпуском выполнять проверки, относящиеся к изменению. Для APK: `python verify.py`, `python test-native.py`, `python test-background-service.py`. Для панели: `node test-launcher.cjs`, `node test-update.cjs`, `node test-catalog.cjs` из source.
Не перезаписывать подписанные выпущенные версии редакторов/инструментов и опубликованные APK отличающимся содержимым. Сначала загрузить и проверить APK, затем публиковать подписанный channel.json. Каталоги проверяет `python scripts/publish.py --verify-only` из корня.
`publication.json` и `.github/workflows/publish.yml` управляют публикацией проверенных файлов в Releases. Полные инструкции — README.md.

## Интерфейс
Компактный интерфейс на русском, без пояснений к очевидным действиям. Не менять поведение редактора при технических изменениях без необходимости.
